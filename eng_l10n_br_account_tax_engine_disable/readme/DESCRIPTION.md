Este módulo permite desativar o cálculo automático dos impostos nas faturas do Odoo.

Essa funcionalidade é útil em situações onde os impostos precisam ser lançados conforme a nota fiscal do fornecedor, como no caso de notas fiscais de importação. Nessas situações, o sistema pode não calcular corretamente os tributos devido à falta de lógica específica para esse caso de uso.

Com este módulo, o usuário pode registrar manualmente os impostos conforme necessário, garantindo que os valores estejam alinhados com os documentos fiscais recebidos.
