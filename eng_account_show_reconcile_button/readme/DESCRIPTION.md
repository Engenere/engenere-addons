Este módulo altera o comportamento padrão do Odoo, exibindo o botão de **Entradas Reconciliadas** na tela de lançamento do diário, mesmo quando não há reconciliações realizadas.
Essa modificação garante que o usuário possa acessar rapidamente a tela de reconciliação, otimizando o fluxo de trabalho e agilizando os processos contábeis.
