Módulo para gerenciamento de consórcios brasileiros (compra de bens via grupo de
consórcio). Permite controlar cotas, parcelas com composição variável, reajustes e
geração automática de faturas de fornecedor.

Principais funcionalidades:

- Cadastro de cotas de consórcio com dados completos (administradora, grupo, cota,
  valores, taxas, contemplação)
- Registro de parcelas com decomposição por componente (fundo comum, taxa de
  administração, fundo de reserva, seguro, multa/juros, etc.)
- Geração automática de faturas de fornecedor com contas contábeis corretas por
  componente
- Wizard de reajuste que recalcula parcelas futuras proporcionalmente
- Registro de lances (antecipações)
- Dashboard com saldo devedor, parcelas pagas/pendentes e próximo vencimento
